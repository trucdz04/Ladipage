# AI Radar — template lấy cảm hứng từ bố cục futuretools.io

Trang tĩnh tiếng Việt dành cho blog review công cụ AI. Nội dung và nhận diện là mẫu riêng; không chứa bài viết, logo hoặc ảnh của trang tham chiếu.

## Chạy local

```bash
node serve.cjs
```

Mở `http://127.0.0.1:8765/`.

## Cấu trúc

- `index.html`: các section và nội dung tĩnh.
- `styles/main.css`: token màu, layout và responsive.
- `scripts/main.js`: dữ liệu thẻ tin/công cụ, tab, menu, theme và form demo.
- `extraction/`: bằng chứng trang nguồn và ảnh kiểm tra.

## Trước khi xuất bản

1. Đổi tên AI Radar, mô tả và nội dung mẫu theo thương hiệu thật.
2. Tạo trang bài viết review thật, rồi thay liên kết hiện trỏ sang website công cụ bằng URL bài tương ứng.
3. Kết nối biểu mẫu email với dịch vụ newsletter; hiện tại form chỉ báo demo và không gửi dữ liệu.
4. Kiểm chứng nội dung sản phẩm, giá và chương trình affiliate tại thời điểm xuất bản; bổ sung thông báo affiliate khi có link hoa hồng.
5. Nếu dùng WordPress, chuyển markup/style thành theme hoặc block template và nối dữ liệu bài viết từ WordPress.
